# Eleventy Starter

A reusable static website framework built with Eleventy.

## Structure

- `_src/` — Website source files
- `_src/_data/` — Global site data
- `_src/_includes/` — Layouts and reusable components
- `_src/assets/` — CSS, JavaScript, fonts and images
- `_src/pages/` — Website pages
- `_src/blog/` — Blog content
- `_site/` — Generated website

## Deployment

This project is designed to be built and deployed automatically using GitHub Actions and hosted on GitHub Pages.

## Local Development

Node.js and npm are not required for GitHub-based deployment.

The GitHub Actions workflow installs dependencies and builds the site automatically.
